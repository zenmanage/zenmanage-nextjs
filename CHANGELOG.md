# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and this project adheres to Semantic Versioning.

## [0.1.0] - 2026-05-07

### Added

- Initial `@zenmanage/nextjs` package scaffold for public distribution
- SSR helpers for App Router and Pages Router evaluation flows
- Middleware/edge-compatible request context helpers
- Hydration-safe bootstrap payload serialization and client defaults helpers
- `NextFlagsProvider` client integration extending `@zenmanage/react`
- High-coverage unit test suite and strict validation scripts
- Comprehensive README, examples, and publishing guide
